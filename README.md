# Gina & Betsabé ❤️

Repositorio listo para publicar con GitHub Pages.

## Estructura
- `index.html` — archivo original de la aplicación, sin modificar.

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` a la raíz.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**.
5. Elige **main** y **/(root)**.
6. Guarda y espera a que GitHub genere el enlace.
